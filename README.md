# Лабораторная работа № 1

Генетический алгоритм для функции Цин. Сухарев Фёдор Дмитриевич, № 23 в группе 527, 2026 год.
По формуле задания `V = 1 + ((17·23 + 7·2 + 26) mod 20) = 12`, размерность `d = 5`.

## Запуск

Нужен Python 3.10 или новее. Из папки `lab1`:

```powershell
python -m pip install -r requirements.txt
python main.py
```

Запуск создаёт папку `results` с итогами 20 независимых запусков для каждого из двух вариантов ГА и случайного поиска. Параметры и начальные значения генератора указаны в [config.json](config.json). Их можно поменять в этом файле и повторить запуск.

Проверка основных свойств реализации:

```powershell
python -m unittest discover -s . -p "test_*.py"
```

## Файлы результатов

- `results/runs.csv` — итог каждого запуска: метод, seed, лучший результат и вектор.
- `results/history.csv` — минимум, среднее и максимум лучшего достигнутого значения по поколениям.
- `results/summary.json` — описательная статистика итогов.
- `results/convergence.png` — графики с логарифмической шкалой по оси значения функции.
- [report.md](report.md) — постановка, алгоритм, анализ результатов и выводы.

Оптимизатор реализован без сторонних библиотек. `matplotlib` нужен только для построения графика.
